# メッセージビルダー (Message Builder)

**直感的なGUI操作でテキストを組み立て、AIチャット用プロンプトを手早く構築するツール**

「メッセージビルダー」は、複数のテキストチャンク（断片）を柔軟に管理・結合して出力できるデスクトップアプリケーションです。
コードスニペットや参照資料、指示文などをクリップボードやGUI操作で集約し、AIへの入力メッセージを効率的に作成できます。

---

## 主な用途・ユースケース
* **AIチャット向けプロンプトの構築**
  * システム指示、コンテキスト情報、コードブロックなどをチャンク単位で整理・結合し、洗練されたプロンプトを素早く生成します。
* **複数のテキスト情報の集約・編集**
  * 各所に散らばったログやコード断片をクリップボード経由で手軽に収集・並び替えて1つのドキュメントとしてまとめます。

---

## 主な機能

### 1. 柔軟なチャンク管理
* **追加・削除・並び替え**: GUI上で直感的にチャンクを整理可能。
* **出力の有効 / 無効切り替え**: 結合対象に含めるかどうかをチャンクごとに手軽にトグル可能。
* **タイプ切り替え**: 
  * **プレーンテキスト**
  * **コードブロック**: 出力時に自動でトリプルバッククォート（` ``` `）で囲んでフォーマット。

### 2. クリップボード連携
* **クリップボード監視**: コピーしたテキストを自動で新規チャンクとして取り込み。
* **ワンクリック出力**: 結合されたテキストを即座にクリップボードへ転送。

### 3. タブ管理 & スタッシュ（データ退避）機能
* **マルチタブ対応**: 複数のメッセージ構築作業をタブで並行管理。
* **スタッシュ機能**: 
  * 現在の作業内容を JSON 形式で退避保存し、自動的に新しい空タブを開いて作業を継続。
  * 後から退避した状態を復元・再利用可能。
